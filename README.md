# 星趴助手（Astral Party Pilot）

> Astral Party Pilot（APP），你的游戏助手，一个能够查询《星引擎 Party / Astral Party》的知识库、对局状态、地图拓扑，并拥有决策函数与陪玩引擎，辅助游玩的Astrbot插件。

**游戏版本：3.3.0（2026-11-12 更新）** · 知识库与素材基线已同步该版本（卡牌 73 / 怪物 70 / 筹码 92 / 角色 36 / 地块 28）

> 更新日志：见 [CHANGELOG.md](CHANGELOG.md)；装好后 AstrBot 面板 → 插件 → 本插件详情 → **更新日志** 也会直接渲染同一份。

[![AstrBot](https://img.shields.io/badge/AstrBot-plugin-2B579A.svg?style=flat-square)](#)[         ![Python](https://img.shields.io/badge/python-3.10%2B-3776AB.svg?style=flat-square&logo=python&logoColor=white)](#环境要求)[        ![Platform](https://img.shields.io/badge/platform-Windows-0078D4.svg?style=flat-square&logo=windows&logoColor=white)](#环境要求)

游戏对局数据解析与自动化操作助手，围绕「读局 → 判断 → 执行」三段闭环构建：从游戏资源与运行时状态中取回地图、手牌与对局进度，用确定性规则算出当前最优动作，再以模拟鼠标输入交给游戏执行。

> [!IMPORTANT]
> **`/appa` 系列（陪玩 / 代打操控）尚在开发中，未完全实装**：
> 指令可能随版本变动甚至临时失效，请以实际体验为准、静待更新。
> 图鉴类（`/app`）正常调用，不受影响。

## 功能

- **图文图鉴**：卡牌 / 地图 / 地块 / Buff / 怪物 / 角色 / 皮肤 / 战斗 CG / 表情包 / 筹码 / 成就，全部渲染成图片卡片
- **筹码图鉴**：92 枚战斗筹码按稀有度（金 → 紫 → 蓝）与流派分组，图标带品质圆盘底，同套系一览 + 单卡效果说明
- **成就图鉴**：139 成就按数字 ID 排序，全成就图鉴以及成就达成条件与奖励
- **实时查号**：`/app <UID>` 查别人（需要一个小号），在局内显示对局进度，不在局显示档案卡（等级 / 胜率 / 获赞 / 最近战绩）
- **扫码登录**：`/app in` 手机扫码feimo通行证登录；登录后 `/app uid` 返回完整档案卡（成就总数、全部角色、角色场次），`/app out` 退出并删除本机登录票
- **陪玩引擎**（⚠️ 开发中）：寻路、手牌、筹码等逻辑；三种操控模式 —— **全自动代打**（`/appa on`）、**半自动代打**（如`/appa card` 临时调试特定逻辑）、**玩家自主操控**（`/appa off`）
- **知识库**：手牌 73 张、Buff 323 条、筹码 92 种（含各地图专属）、成就 139 个、怪物 70 种、角色 36 位、地块 28 种、地图拓扑 21 张等，随插件分发、离线可查

## 环境要求

- **AstrBot**（插件宿主）
- **Python 3.10+**
- **Windows**（陪玩引擎的鼠标输入依赖 Win32 API，图鉴部分跨平台可用）

全量解包（`/app load`），插件会按当前机器的 CPU 和内存自动调配，但请务必保证足够的内存空间（推荐`2G`以上）, 8 进程解包时间约为200s。全量解包前可先`/app check`检查资源调配情况。

| 项目  | 自动调配                                        | 参考量级                                         |
| --- | ------------------------------------------- | -------------------------------------------- |
| 并发  | 上限＝**物理核数**，实际再按可用内存压                       | 8 核 CPU 最多 8 进程；只剩 2GB 内存时降到 2 进程（所需时间翻 4 倍） |
| 内存  | 1GB 系统余量，每进程 330MB；按余量动态决定多少 `bundle` 换一次进程 | 8 进程实测峰值约 2.3GB                              |
| 磁盘  | 低于 1GB 直接拒绝，1～3GB 只提示                       | 输出约 1.7GB / 6600 张图                          |

## 安装

1. 将本插件放入 AstrBot 的 `data/plugins/` 目录
2. 在 AstrBot 插件管理页启用

### 辅助游玩（`/appa`）需另下注入包

插件市场包不含注入文件`doorstop + BepInEx + AstralProbe.dll`，主要考虑到以下因素：

1. **避免误检测**：注入文件是**未签名的游戏模组二进制**（`winhttp.dll` 是 doorstop 注入器、
   `BepInEx/core/*.dll` 是运行时、`AstralProbe.dll` 是插件本体）。这类文件长期是杀软 / 引擎启发式报毒的常客（VirusTotal 上也常有个别引擎命中），如果和 Python 源码混在同一个包体里，自动安全检查会把整个插件标成可疑；
2. **体积与审核口径**：这些二进制只服务 `/appa`，图鉴 / 查号并不需要它们。

要开辅助游玩，需自行下载注入包 `appa-v2.4.0-beta1.0`：

1. 到 [**Releases**](https://github.com/Ruoyuezero/astrbot_plugin_astralparty_pilot/releases) 下载
   **`appa-v2.4.0-beta1.0.zip`**
2. 解压到插件目录 `data/plugins/astrbot_plugin_astralparty_pilot/`，合并后应当看到
   `pkg/payload/winhttp.dll`等文件（压缩包 `pkg/payload/…`，勿多套一层目录）
3. 完全退出游戏后发 `/appa`（仅管理员）完成注入

## 配置

插件有 11 项配置，都在 AstrBot 面板 → 插件配置里：

| 配置项               | 说明                                                                                       |
| ----------------- | ---------------------------------------------------------------------------------------- |
| `art_root`        | 美术素材库目录（父目录）。**留空实时解包，会有轻微瞬时占用**                                                         |
| `load_mem_limit`  | 解包内存上限（MB，0＝自动），一般不用填                                                                    |
| `card_font`       | 卡面字体族（默认黑体）                                                                              |
| `live_client_ver` | 查号客户端版本号，留空自动读，一般不用填                                                                     |
| `alt_sid`         | 查别人时用的小号登录票 sid（**推荐填**，取法：发 `/appa sid` 复制`sid`粘贴；留空＝默认用本机第一条登录票，见下文「查询账号`/app <UID>`」） |
| `deploy_src`      | `/appa` 注入源目录，留空＝用插件自带的 `pkg/payload`                                                        |
| `pilot_prefer`    | 代打默认倾向（发育 / 进攻 / 防守）                                                                     |
| `login_port`      | `/app in` 登录网页端口（默认 0＝自动挑空闲端口；监听地址见 `login_lan`）                                             |
| `login_lan`       | 允许局域网扫码，**默认关**。关＝只监听 `127.0.0.1`（端口不暴露，手机扫不到，改用 `/app in <手机号>`）；开＝监听 `0.0.0.0`，手机可扫码 |
| `login_host`      | 二维码里用的主机地址，留空自动探测局域网 IP；有域名/端口映射才填                                                       |
| `admin_qqs`       | 管理员 QQ，逗号分隔。`/appa` 整套指令仅管理员本地使用；留空＝只认 AstrBot 全局管理员                                     |
| `emoji_fps`       | 动态表情出 GIF 的帧率（5~60，默认 30）。游戏里动态表情是一张序列图，插件按这个帧率拼成 GIF                                            |
### 美术图库

插件本体只带字体和 logo，不含任何游戏素材。素材全部来自外部库：

1. 在面板里把 `art_root` 填成想放素材的父目录（不用自己建子目录）
2. 发 `/app load`
3. bot 会从游戏本体（Steam 里的《星引擎 Party》）解包全部 `Texture2D`，写进
   `<art_root>\Astral Party\<类别>\<资源名>.png`，解包统计另存插件数据目录

图库按英文子目录分类：`chibi` / `portrait` / `cg` / `emoji` / `land` / `card` / `buff` / `relic` / `achieve` / `cardback` / `headshot` 等三十来类。

- 素材只能从游戏本体解包，所以电脑需要安装《星引擎 Party》
- **完整性自查**：插件数据目录存在完整性清单，解包结束后会进行完整性验证，见`data/plugin_data/astrbot_plugin_astralparty_pilot/art_index.json`
- **实时解包（`art_root` 为空）**：利用「图名 → bundle」映射表实时生成图鉴。`/app load`的功能为检查映射表是否可用，无异常返回「✅ 映射表已就绪，无需重建」
- **外库不可用自动回落**：`art_root` 路径不存在，如盘符写错 / 移动硬盘未插入等，bot 自动改用实时解包，同上。

### 查询账号`/app <UID>`

国服是**单点登录**，bot 联机握手用的是「登录票 sid」，如果使用本机正在登录号去握手，会把当前游戏登录账号顶下线。
查询分成两条路径：

- **`/appa me`**（仅管理员）：查本机登录账号，本地不联网 
  在局内（`state.json` 20 秒内还在更新）读探针实时写出的全桌状态返回局内进度卡，不在局返回档案卡，见`plugin_data`/`profile_cache.json` 
- **`/app <UID>`**：查他人账号，联机查服务器数据（在线状态 / 角色场次 / 战绩等）。为避免顶掉主号，请在插件配置页面填写暂不游玩的小号`sid`实现握手。

`alt_sid` 填写方法：

1. 发 **`/appa sid`**，bot 根据账号`uid`列出本机所有登录票，复制小号`uid`对应的`sid`，粘贴到插件对应配置项保存即可。
**【注意】 请不要在群聊中发送 /appa sid 指令**

或者：

1. 准备一个暂不游玩的小号，在游戏里登录
2. 打开 `%USERPROFILE%\AppData\LocalLow\feimo\<客户端>\BnSdk\<AppID>\Log` 下最新的日志
3. 找 `login success, sid`: 复制后面那串进 `alt_sid`

### 登录账号`/app in`

`/app <UID>` 是查询他人账号，服务端只给公开数据，角色卡列表只有一个数量，成就数量、角色场次等只有账号登陆者可见。想查看自己完整档案，请登录账号：

1. 发 **`/app in`** → bot 回复一张二维码以及网页链接，手机扫码打开登录页
2. 页面上填 **feimo通行证绑定的手机号** → 收短信验证码 → 登录
3. 登录成功后发 **`/app uid`** → 完整档案卡

> **扫码需要打开「允许局域网扫码」（`login_lan`）**：该项默认关闭，登录网页只监听 `127.0.0.1`，
> 端口不对局域网暴露，但手机扫不到页面。两种用法任选：
> - 想扫码：配置里把 `login_lan` 打开 → 再发 `/app in`（该端口只在那次登录的约 10 分钟内开放，别映射公网）
> - 不开放端口：直接 **`/app in <11 位手机号>`** 收短信验证码，效果一样

> 换设备、久不使用、官方踢登录态都会让 sid 失效，需要重新登录；
> 已经登录、且登录票还在有效期内时，`/app in` 返回当前登录状态；
> 发生异常需要强制重新登录用 `/app in force`；
> 登录票绑定QQ，sid与QQ号一一对应，换号先退出登录 `/app out`。
