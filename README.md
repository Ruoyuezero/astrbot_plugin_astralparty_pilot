# 星趴助手（Astral Party Pilot）

> AstrBot 插件：把《星引擎 Party / Astral Party》（国服《吉星派对》）的对局知识库、地图拓扑、决策函数与陪玩引擎搬进 QQ。

[![AstrBot](https://img.shields.io/badge/AstrBot-plugin-2B579A.svg?style=flat-square)](#)
[![Python](https://img.shields.io/badge/python-3.10%2B-3776AB.svg?style=flat-square&logo=python&logoColor=white)](#环境要求)
[![Platform](https://img.shields.io/badge/platform-Windows-0078D4.svg?style=flat-square&logo=windows&logoColor=white)](#环境要求)

游戏对局数据解析与自动化操作助手，围绕「读局 → 判断 → 执行」三段闭环构建：从游戏资源与运行时状态中取回地图、手牌与对局进度，用确定性规则算出当前最优动作，再以模拟鼠标输入交给游戏执行。

---

## 功能

- **图文图鉴**：卡牌 / 地图 / 地块 / Buff / 怪物 / 英雄 / 皮肤 / 战斗 CG / 表情包 / 筹码 / 成就，全部渲染成图片卡片
- **筹码图鉴**：89 枚战斗筹码按稀有度（金 → 紫 → 蓝）与流派分组，图标带品质圆盘底，单卡给效果说明 + 同套系一览
- **成就图鉴**：134 个成就按数字 ID 排序，一张图看全插画，单卡给达成条件与奖励（货币原币 + 数量）
- **实时查号**：按 UID 查玩家，在局内显示对局进度，不在局显示档案卡（等级 / 场次 / 胜率 / 获赞 / 拥有角色 / 最近战绩）；查本机登录的账号时额外给成就进度，任何人的卡都会显示其资料页展示的成就
- **陪玩引擎**：威胁排序、寻路、手牌建议，支持「只看不动」的辅助模式和自主代打
- **知识库**：手牌 71 张、Buff 311 条、筹码 89 种（含各地图专属）、成就 134 个、怪物 69 / 英雄 / 地图拓扑 21 张等，随插件分发、离线可查

#### 筹码与成就图鉴说明

- **筹码**：全库 89 枚。有专属图标的 70 枚带游戏内编号（如 `1001`），19 枚纯属性筹码（攻击 / 防御 / 生命 / 速度等）共用 8 张通用图标、无编号，卡片会标注「纯属性筹码 · 无图标编号」。
- **排序**：先按稀有度 金 → 紫 → 蓝，同品质内再按流派——通用系 / 星光系 / 治愈系 / 标记系 / 充能系，以及梦想号、御魂庆典、水乡古镇、魔法学院、龙宫游乐园、幽魂暗巷、园林中庭、运动场、决赛大赛场、异变图书馆等地图专属。
- **品质底框**：游戏包内没有独立的稀有度框贴图，插件用解包出的 `UT_RelicBase_Blue / Purple / Orange` 圆盘做底（图库缺失时按品质色渐变自绘），单卡效果说明紧贴「品质 · 流派 · 编号」下方。
- **成就**：全库 134 个，编号即游戏内成就 ID；列表一张图按 ID 排序展示插画与中文名，单卡展示达成条件与奖励（原币图标 + 数量）。
- **玩家的成就进度能查到多少**：服务端「展示玩家」接口只返回资料页展示墙上自选的几个成就 ID，**没有查询他人成就总数的接口**；完整进度只在登录包的任务字段里（已领取奖励的成就 ID 列表），所以查本机登录的账号时档案卡会多一行「成就 N 项」，查别人只能看到展示墙那 6 个。

## 环境要求

- **AstrBot**（插件宿主）
- **Python 3.10+**
- **Windows**（陪玩引擎的鼠标输入依赖 Win32 API，图鉴部分跨平台可用）

---

## 安装

1. 将本插件放入 AstrBot 的 `data/plugins/` 目录
2. 在 AstrBot 插件管理页启用
3. （可选）配置美术图库根目录与游戏目录，见下文「配置」

---

## 配置

### 美术图库

图鉴图片默认从外部图库读取（`art_root`，默认 `F:\pictures\Astral Party`），按英文子目录分类组织（`portrait` / `cg` / `emoji` / `land` / `card` / `buff` / `relic` / `achieve` / `item` / `cardback` / `headshot` 等）。插件本体只内置字体与 logo，不含游戏素材；图库缺图时会退化为纯文字卡片，不会报错。

### 游戏目录（陪玩用）

陪玩引擎按以下优先级定位游戏实例目录，**无需手动填也能自动探测**：

1. 插件配置 `pilot_game_dir`
2. 环境变量 `ASTRAL_GAME_DIR`
3. 工程 `config.json` 的 `game_dir`
4. **自动探测**：读 Steam 注册表 + `libraryfolders.vdf` + `appmanifest` 定位 `common/Astral Party/<实例>`
5. 硬编码兜底

## 目录结构

```
astrbot_plugin_astralparty_pilot/
├── main.py               插件入口（/app 与 /星趴 两个指令）
├── pkg/                  渲染、知识库读取、陪玩进程管理等模块
│   ├── gamepath.py       游戏目录自动探测（Steam 库扫描）
│   └── ...
├── pilot/                陪玩引擎（子进程拉起，插件核心）
├── kb/                   知识库（手牌 / Buff / 怪物 / 英雄 / 筹码 / 成就 / 地图拓扑）
│   ├── relics.json       筹码 89 条（名称 / 品质 / 流派 / 编号 / 图标 / 效果）
│   └── achievements.json 成就 134 条（ID / 名称 / 达成条件 / 奖励）
├── maps/                 地图拓扑数据
├── fonts/                内置字体（含 MSUIGothicCN 混合字体）
├── images/               内置图片
├── logo.png
├── metadata.yaml
└── _conf_schema.json     配置项定义
```
