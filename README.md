# 星趴助手（Astral Party Pilot）

> AstrBot 插件：把《星引擎 Party / Astral Party》（国服《吉星派对》）的对局知识库、地图拓扑、决策函数与陪玩引擎搬进 QQ。

[![AstrBot](https://img.shields.io/badge/AstrBot-plugin-2B579A.svg?style=flat-square)](#)[         ![Python](https://img.shields.io/badge/python-3.10%2B-3776AB.svg?style=flat-square&logo=python&logoColor=white)](#环境要求)[        ![Platform](https://img.shields.io/badge/platform-Windows-0078D4.svg?style=flat-square&logo=windows&logoColor=white)](#环境要求)

游戏对局数据解析与自动化操作助手，围绕「读局 → 判断 → 执行」三段闭环构建：从游戏资源与运行时状态中取回地图、手牌与对局进度，用确定性规则算出当前最优动作，再以模拟鼠标输入交给游戏执行。

---

## 功能

- **图文图鉴**：卡牌 / 地图 / 地块 / Buff / 怪物 / 角色 / 皮肤 / 战斗 CG / 表情包 / 筹码 / 成就，全部渲染成图片卡片
- **筹码图鉴**：89 枚战斗筹码按稀有度（金 → 紫 → 蓝）与流派分组，图标带品质圆盘底，单卡给效果说明 + 同套系一览
- **成就图鉴**：139 个成就按数字 ID 排序，一张图看全插画，单卡给达成条件与奖励（货币原币 + 数量）
- **实时查号**：`/app <UID>` 查别人，在局内显示对局进度，不在局显示档案卡（等级 / 场次 / 胜率 / 获赞 / 最近战绩）；查别人用小号 sid 握手，不顶主号。看本机用 `/appa`（局内出局内卡，不在局出档案卡，仅管理员）
- **扫码登录**：`/app in` 出二维码，手机扫码用飞魔通行证手机号 + 验证码登录（也支持 QQ 内直接收码）；登录后 `/app uid` 出完整档案卡（成就总数、全部角色卡、每角色场次），`/app out` 退出并删除本机登录票
- **陪玩引擎**：威胁排序、寻路、手牌建议；三种操控模式 —— **全自动代打**（`/appa on`）、
  **半自动代打**（`/appa card` 等把某一项交给 bot）、**玩家自主操控**（`/appa off`）
- **知识库**：手牌 71 张、Buff 311 条、筹码 89 种（含各地图专属）、成就 139 个、怪物 69 / 角色 / 地图拓扑 21 张等，随插件分发、离线可查

## 安装

1. 将本插件放入 AstrBot 的 `data/plugins/` 目录
2. 在 AstrBot 插件管理页启用
3. **想看图鉴出图**（可选，不出图也能查文字）：在插件配置里把 `art_root` 填成放素材的父目录（例如 `F:\pictures`），保存后发 `/app load`，bot 会从游戏本体解包美术素材 —— 细节见下文「美术图库」

## 配置

插件有 8 项配置，都在 AstrBot 面板 → 插件配置里：

| 配置项 | 说明 |
|---|---|
| `art_root` | 美术素材库目录（父目录）。**留空＝没有图库，图鉴一律不出图** |
| `card_font` | 卡面字体族（默认黑体） |
| `live_client_ver` | 查号客户端版本号，留空自动读，一般不用填 |
| `alt_sid` | 查别人时用的小号登录票 sid（**推荐填**，见下文「查号与防顶号」） |
| `pilot_prefer` | 代打默认倾向（发育 / 进攻 / 防守） |
| `login_port` | `/app in` 扫码登录网页端口（默认 0＝自动挑空闲端口，只监听局域网） |
| `login_host` | 二维码里用的主机地址，留空自动探测局域网 IP；有域名/端口映射才填 |
| `admin_qqs` | 管理员 QQ，逗号分隔。`/appa` 整套指令只给这些人用；留空＝只认 AstrBot 全局管理员 |

### 美术图库

插件本体只带字体和 logo，**不含任何游戏素材**。图片全部来自外部图库：

1. 在面板里把 `art_root` 填成想放素材的目录，例如 `F:\pictures`（填父目录，不用自己建子目录）
2. 发 `/app load`
3. bot 会从游戏本体（Steam 里的《星引擎 Party》）解包全部 `Texture2D`，写进
   `<art_root>\Astral Party\<类别>\<资源名>.png`，同时在图库根目录留一份 `manifest.json` 记录这次的统计

之后所有图鉴（`/app hero`、`/app card`、`/app relic`……）都从这个库出图。图库按英文子目录分类：`chibi` / `portrait` / `cg` / `emoji` / `land` / `card` / `buff` / `relic` / `achieve` / `cardback` / `headshot` 等三十来类。

- `art_root` 留空时发 `/app load` 会直接报「加载失败」，提示去配置，不会假装成功
- 素材只能从游戏本体解包，所以这台机器得装着《星引擎 Party》；找不到游戏目录同样报「加载失败」
- 已经存在的文件默认跳过，所以重复跑只补新素材；游戏更新后重新发一次即可
- 全量解包 6688 个 bundle，多进程实测约 2 分钟，跑在后台，完成后 bot 主动把结果发回来
- 想先看看现状不发车：`/app load check`
- 图库缺图时会退化为纯文字卡片，不会报错
- 从 1.9.1 起启动时会自动整理配置：删掉旧版废弃项（`art_source` / `*_dir` / `live_host` 等），`art_root` 若误填成 `…\Astral Party` 也会自动回退成父目录

### 查号与防顶号

国服是**单点登录**：同一个账号只能在线一处，bot 联机握手用的是「登录票 sid」，如果拿本机正在玩的号去握手，会把游戏顶下线。所以查号拆成两条：

- **`/appa`**（仅管理员）：看本机，**全程不联网** —— 联机会把大厅里正开着的号顶下线。
  在局内（`state.json` 20 秒内还在更新）读探针实时写出的全桌状态出局内卡；
  不在局出**档案卡**：和 `/app uid` 用的是同一个渲染函数，数据换成本地的 —— 之前查过的号用
  `data/profile_cache.json` 里存的档案，没查过就用本机 `state.json` / `accounts.json` 现拼一张
  （战绩那几格显示「—」，并提示发一次 `/app uid` 补齐）。
- **`/app <UID>`**：查别人，联机查服务器数据（在线状态 / 档案 / 战绩）。为避免顶掉主号，**用 `alt_sid` 配的小号去握手**。

`alt_sid` 怎么填：

1. 准备一个**不玩的小号**，在游戏里登录它
2. 打开 `%USERPROFILE%\AppData\LocalLow\feimo\AstralParty_CN\BnSdk\110001933\Log` 下**最新**的日志文件
3. 找 `login success, sid: 后面那串`，复制进 `alt_sid`

注意：充当代理的小号**平时要退出游戏**（离线状态），它的 sid 才能被 bot 用来查号；小号若开着游戏在线，用它握手一样会被判双登、把小号顶下线。`alt_sid` 留空时，查别人退回用本机最近登录票（会顶掉本机主号，不推荐）。

### 登录账号（看完整档案）

`/app <UID>` 走的是"查别人"的口径：服务端只给公开数据，角色卡列表只有一个数量，
成就进度、每个角色的场次这些只有本人可见。想看完整档案，就用登录：

1. 发 **`/app in`** → bot 回一张**二维码**，手机扫码打开登录页
2. 页面上填**飞魔通行证绑定的手机号** → 收短信验证码 → 登录
3. 登录成功后发 **`/app uid`** → 完整档案卡（成就总数、全部角色卡、每角色场次）
4. 不想用了发 **`/app out`** → 删掉本机保存的登录票

细节：

- **登录票（sid）怎么存**：`data/accounts.json`，按 QQ 一人一条，互不影响。
  Windows 上用 DPAPI 加密（只有本机本用户能解开），其他系统落 0600 权限文件。
  聊天里只出现打码后的手机号，**任何指令都不回显 sid**；要清掉它只发 `/app out`。
- **手机扫不开怎么办**：登录页由插件自己起在 `login_port`（默认自动挑端口）上，
  只监听局域网。手机和 bot 不在同一网络时，用兜底方式：
  `/app in <11 位手机号>` → 收短信 → `/app in <6 位验证码>`。
  若 bot 跑在有域名/端口映射的服务器上，把 `login_host` 填成对外地址。
- **会不会顶号**：`/app in` 只是拿票，不连游戏服务器；但 `/app uid` 要连服务器查数据，
  同一账号**不能双登**。账号正开着游戏（大厅或对局）时，bot 会直接顶号登录，
  **不用先退游戏**——被顶的那一端重连一下就好。
- **票会过期**：换设备、久不使用、官方踢登录态都会让 sid 失效，
  表现是查档案报 `10000`（登录票无效），重新 `/app in` 一次即可。

### 游戏目录（陪玩用）
陪玩引擎按以下优先级定位游戏实例目录，**无需手动填也能自动探测**：

1. 环境变量 `ASTRAL_GAME_DIR`
2. 插件目录下 `config.json` 的 `game_dir`（可选，一般不建，靠自动探测就够）
3. **自动探测**：读 Steam 注册表 + `libraryfolders.vdf` + `appmanifest` 定位 `common/Astral Party/<实例>`

全都找不到时直接报「找不到游戏目录」，不会再兜到某个写死的本机路径上。
