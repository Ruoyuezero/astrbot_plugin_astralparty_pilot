## 二、筹码（relic）

### 2.1 按定位选筹码

| 定位 | 主要筹码类型 | 典型筹码 |
|---|---|---|
| 物理输出 | 攻击型 | 拳套、美工刀、肾刀、瞄具 |
| 法系输出 | 出牌型 | 大背包、书签、飞镖、可口糖果、法杖、喷罐 |
| 辅助 | 辅助型 | 徽章、炖肉、银行卡、头盔、饼干 |

### 2.2 分系规则（硬约束）

- 筹码分**通用系** + 四个系：治愈系、标记系、星光系、充能系。
- 只能拿**通用系 + 其中两系**。
- 一旦拿到两种不同系，剩下两类就再也拿不到 —— 这就是**筹码分系**。
- 常规选择：
  - 输出型 → 治愈系 + 标记系
  - 辅助型 → 星光系 + 治愈系
  - 充能系一般只在高难图用，此时输出可以选充能系

### 2.3 系强度

治愈系 > 标记系 ≈ 星光系 > 充能系

> 充能系偏生存，伤害最低；治愈系伤害高于标记系。

### 2.4 必拿系（角色定了就必须走这个系）

| 系 | 必须拿的角色 |
|---|---|
| 标记系 | 121、127 |
| 星光系（钱辅：给主 C 转账，拿到飞星后路过怪物一路放过即可造成伤害） | 101、102、108、114、305 |
| 治愈系 | 112、123、302、304 |

## 三、升星与金币

| 星 | 花费（星币） |
|---|---|
| 1 星 | 15 |
| 2 星 | 20 |
| 3 星 | 25 |

- 输出型角色**优先升星**，达到 2 星后才允许买筹码。
- 但大多数情况还是优先冲 3 星。
- 星级越高，开出好筹码的概率越高。
- 地图任务给筹码，**优先完成任务**提升实力。
- 攻击力足够高就可以去打 BOSS，击败即胜利。

## 四、买牌逻辑

### 4.1 输出型

- 0 星且金币低于 18 → **禁止买牌**。
- 达到 1 星后可以买牌，主要买攻击牌。
- 攻击牌超过 4 张后，不再买普通攻击牌（费用 < 4 的），但可以买 **嘎呜切、蓄力**（费用 > 3 的高级攻击牌）。

### 4.2 辅助型

- 优先把金币转给输出型角色，帮其升星。
- **不可以随意买牌。**

## 五、战斗逻辑

### 5.1 攻击

1. 若 `攻击力 > 该怪防御力 + 生命值` → 直接攻击。
2. 否则判断该怪会不会反击：
   - 不会反击 → 直接打。
   - 会反击 → 看手里有没有攻击牌，若 `攻击力 + 可出攻击牌期望伤害 > 怪防御 + 生命值` → 打；否则放过。
3. **打小偷不使用攻击牌**（2026-11-04 主人口述）—— 小偷**直接点攻击就搞定**，不用出牌、不用垫伤害。

### 5.2 防御

1. 若 `怪物攻击力 < 自己防御值 + 2` → 不需要防御牌，直接防御。
2. 若 `怪物攻击力 > 自己防御值 + 2` → 需要防御牌，差值为 x，选防御牌使**期望防御达到 x**。

### 5.3 期望值算法

- 期望取牌面随机区间的**中值**。
- 可出牌的费用上限：1 星最高 4 费，之后每多一星 +1，3 星最高 6 费。
- 出牌时**优先消耗费用更低的牌**（同样的期望下，先烧便宜的）。
- 例：1 星，防御牌 1 费 ×2、2 费 ×2、3 费 ×1，可出费用上限 4。
  - 3 费 ×1 + 1 费 ×1 → 防御 2~13，期望 7.5
  - 2 费 ×2 → 防御 2~12，期望 7
  - 2 费 ×1 + 1 费 ×2 → 防御 3~12，期望 7.5 ← 优先这个（费用更低）
- 攻击牌同理。

### 5.4 卡牌费用表（2026-11-04 口述）

**效果牌统一 0 费**：加攻、加防、治愈、上标记这类效果牌本身不消耗费用，
出牌也不另外付出任何成本 —— 所以不存在「出不起」的问题，难点只在**什么时候用、用哪张**。

带费用的牌（逐个核过 `kb/cards.json`，`/app card <id>` 也能查）：

| 10002 | 防御(中) | 防御 | 1 | 防御力 +1~3 |
| 10003 | 攻击(大) | 攻击 | 2 | 攻击力 +1~6 |

- 10012 / 10013 只有真梦梓能出，别的人拿到也用不了。

### 5.5 免反击牌（10008 暗影突袭 / 10011 毒牙）的用法

这两张牌的价值不在伤害，而在**「本次攻击无法被反击」**这条：
- 10008 暗影突袭：2 费，攻击力 +3，本次攻击无法被反击。
- 10011 毒牙：2 费，移除目标 2 层【金鳞】，本次攻击无法被反击（龙宫游乐园、帮天川真梦梓时的专属牌）。

使用规则：
1. **只对「会反击」的怪物使用。** 打不会反击的怪用它们纯属浪费——免反击效果一文不值，伤害还不如普通攻击牌。
2. **要打会反击的怪，先看能不能 100% 击飞。**
   - 能保证一击击飞（我方攻击力 + 牌面最低伤害 ≥ 怪的防御 + 生命，取最坏情况）→ 直接按 5.1 打，不必绕道用免反击牌。
   - **不能 100% 击飞 → 用 10008**，靠「无法被反击」白吃这一次攻击，不挨反击伤害。
3. 10011 额外削 2 层金鳞，龙宫图遇到叠甲怪优先考虑它；但别的地图/别的角色没有这张，不要把判定写成「有 10011 就上」。
4. 判定口径统一按 5.3：取牌面**最坏情况**判断能否击飞，「大概能打死」不算 100%。

## 七、代码侧读取口径（2026-11-04 核实）

- **筹码 id ↔ 条目**：`kb/relics.json` 的 `no` 字段**就是**游戏内 id —— 例：50033 = 可口糖果（治愈系·紫）、50053 = 大铁锚、50036 = 「8面」骰子。`kb.relic(50033)` 直接拿 name / quality / faction；另有 `kb/relic_no_map.json` 共 90 条 id → 名称/图标/品质。候选下发的只有 id 也完全够选筹码。
- **星级**：局内 state 的 player 里有 `star`（旧版叫 `lv`），`pkg/livecard.py` 的局内卡就在读它；`/app <UID>` 查别人的局内卡走房间详情里的 hero 快照，同名字段。`pkg/coach.py` 的 `me` 白名单只挑了 hp/atk/def/gold 等 9 项，把 star 过滤掉了 —— 补进白名单即可用于升星门槛判定。

## 八、战斗界面读数补充（2026-11-04）

- **怪物属性只认 FIGHT 开场三图标**：❤ = 血量、剑 = 攻击、蓝盾 = 防御。
- 战斗页中间那条「ATTACK 8 - 8 / DEFENSE」**不是怪物防御值**，不要拿它当防御读，判定一律走 5.1 的式子。
- 实测例：我方攻击 8，鲨鱼图鉴 1 防 2 血 → 8 > 1+2，走 5.1 第一条「直接攻击」，不需要出牌。

## 九、代打命令逻辑（/appa buy · atk · def · dodge · skip · relic）

> **授权是叠加的**：`/appa card`、`/appa skill`、`/appa go` 连着发，三个授权会同时留着 ——
> 一个回合本来就是 出牌 → 技能 → 移动。`/appa on` 才是全覆盖，`/appa off` 清空全部。
> 动作类子命令都是**一次性**的：做成了静默不回话，**做不成会回一条说明 + 理由**
> （如 `/appa card` 手牌里没有能出的牌、`/appa buy` 不在商店、`/appa go` 不在移动阶段），
> 说明发出后这一项授权自动收回，要再来一次就再发一遍。等 8 秒还没动手也按「没做成」处理。

### 9.1 /appa buy —— 经过商店时：购买（2026-11-04 实测跑通）

界面构成：三张卡并排 + 下方「购买！-N」粉键 + 「返回」蓝键，右上「刷新 ×N」。

流程：
1. 逐张看牌名/费用/效果，按第四节 4.1 判「要不要买」。
   - 输出型：0 星且金币 < 18 → 不买；1 星后可买，优先攻击牌；攻击牌已 ≥ 4 张后只买嘎呜切、蓄力这类高费攻击牌。
   - 三张都不是目标（如全是回复/移动/防御）→ 商店**不能刷新**，直接点「返回」走人。
     （「刷新 ×N」只出现在「请选择一枚战斗筹码」界面，见 9.4；商店页没有这个键。）
2. 决定买哪张 → 点那张牌（选中后卡面出现蓝/绿框，购买键价格跟着变）→ 点「购买！」。
3. 成功后该卡位变 **SOLD OUT**，金币减少，牌进右下角手牌；其余两张仍在，可继续买或直接返回。
4. 点「返回」离开商店；返回后常紧接着弹事件卡（如 NEWS-012「食品安全」），点一下就关掉，然后回到地图。
5. 实测记录：第 2 轮商店，金币 32，买到「操控骰子」3 费 → 金币 32→29，手牌变为 王之力 / 攻击（特大）/ 防御（中）/ 操控骰子。

要点：购买键位置别写死，扫粉色段算中心更稳（此前目测坐标点偏过一次）。

### 9.2 /appa atk —— 经过怪物时：攻击

- 触发时机：路过/停在怪物格时替玩家选择「迎战」。
- 打不打、要不要补牌，一律走 **5.1**：攻击力 > 敌方防御 + 敌方当前血量 → 直接打；打不穿才看手牌与是否反击。
- 怪物属性只认 FIGHT 开场 ❤/剑/蓝盾（见第八节），「ATTACK 8-8」不是防御值。

### 9.2b 站在怪物突击门（t=21）上：先选怪，再谈打不打（2026-11-05 口述）

- 判定：`map.json` 的 `lands` 里按 `state.players[].node` 找到当前格，`t == 21` 就是怪物突击门。
- 第一次 `/appa atk`：在突击界面上替你**选一只怪**（选中即传送到怪物格），然后弹出的 5047 才决定打不打。
- 再发一次 `/appa atk`：5047 选「打」。
- 改发 `/appa skip`：同样选怪传送过去，但 5047 选「放过」—— 只过去，不动手。
- 开打之后进战斗界面（FightWindow 在树里就算开着）：再发一次 `/appa atk` = 点那颗
  **READY / 攻击** 键（舞台 512,761）。这一步不看手牌，有 atk 就按，不会替主人挑战斗牌。
  整条链：站突击格 → `/appa atk` 选怪 → `/appa atk` 打（5047）→ `/appa atk` 点 READY 攻击。

### 9.2c /appa card 在战斗界面出战斗牌（2026-11-06 主人补）

- 战斗界面（UI 树里有 `FightWindow`）开着时，`/appa card` 也管战斗牌：
  挑一张手牌里能用的**攻击 / 防御**牌拖进战斗区（和效果牌一样拖到舞台中心）。
- 战斗里 `state` 的 `usable` 是**空的**，能出什么得自己算，判据全在 `state.fight` 里：
  - 谁是攻击方：`fight.attacker.pid == selfPid` 就只能出**攻击**牌，否则只能出**防御**牌
    （kb 里写明：攻击牌「战斗中攻击方可用」、防御牌「战斗中防御方可用」）
  - 费用：卡的 `cost` 不得超过 `fight.<我方>.cost`（本轮可用费），不够就跳过并说明
  - 同类型里先挑便宜的，再按卡号，保证一轮里挑法稳定
- 出完**不替你按 READY** —— 结算是 `/appa atk` 的事，节奏留给你。
- 授权优先级：`atk` 在场时先点 READY（"打小偷直接点攻击"的老路子不变），
  只有单独 `/appa card` 时才走这条出牌路径。
- 判定战斗界面带 1 秒缓存：导 UI 树贵，不能每帧导；离开战斗时顺手把旧原因清掉。
- 没出成时异常说明直接给原因：`手牌里攻击牌费不够（攻击方可用 1 点）：《名刀：嘎呜切》4费`／
  `手上只有防御牌，这轮我是攻击方，用不上`／`《XX》没出成（拖进战斗区没生效）`。
- 选怪键的名字还没实测定死，引擎按 path 含 `Teleport / Assault / AttackGate / PK` 宽松匹配，
  名字含 `atk / attack / fight / pk / ok / confirm` 优先；一次都没认出来时日志里会打一行
  `[突击门] …（候选 …）`，把候选名念给它听就能定死。兜底坐标 `GATE_ATK_POS` 目前是 None（不点固定位置）。

### 9.3 /appa skip —— 跳过（不含闪避）

- 经过怪物格、商店格、筹码界面时：不进入，直接走过（买牌、迎战、选筹码都省下）。
- 出牌阶段：点「取消」，这轮不出牌。
- 战斗界面：点「放过」，不打这只。
- **不管闪避** —— 闪避已拆到 9.3b /appa dodge。

### 9.3b /appa dodge —— 闪避

- 只管一件事：被怪物反击 / 怪物回合被攻击（协议 5039）时选**闪避**（dodge=true）。
- 只授 dodge 时，5047「是否开战」不替主人决定；atk 与 dodge 同时授权以 atk 为准（要打就别躲）。
- 防御与闪避的取舍代价待补。

### 9.4 /appa relic —— 战斗筹码三选一

- 只在「请选择一枚战斗筹码」界面动作，判定依据 2.2 分系：只拿通用系 + 目标两系。
- 输出型：治愈系 + 标记系；辅助型：星光系 + 治愈系。
- 三张都没踩到目标系 → 用右上「刷新」（最多 2 次）；仍无交集就挑收益最高的一张带走。
- 实测：金币/移动类/充能系全部跳过，刷新两次后拿「标靶」（攻击 +1，回合开始给 4 格内最近怪物挂标记），攻击 8→9。

> 待主人补的细节：atk 的迎战按钮位置、闪避与防御的取舍代价。

## 十、出效果牌逻辑（2026-11-05 口述）

出效果牌（0 费）阶段按下面几条调权重，属于被动牌的优先顺序：

### 10.1 攻击力高 —— 走位类
- 自身攻击 **> 7** 时，提高：
  - 20005《遥控骰子》—— 移动到突击格攻击怪物
  - 20010《路障》—— 放到突击格攻击怪物

### 10.2 升星相关 —— 走位类
- 满足升星条件，且背后（来的方向）有更近的升星点 → 用 20011《方向抉择》移动到自己的出生点 / 保障点
- 满足升星条件，但前方出生点不是自己的出生点 → 用 20010《路障》放在该出生点，经过时停留升星

### 10.3 按血量分档 —— 回血 / 打怪 / 养属性

## 十二、授权机制：单次 / 常驻

单项授权（`/appa card`、`/appa skill`、`/appa go`、`/appa atk` …）是**调试单个动作**用的：

- 写进 `coach_ctl.json` 时带 `once` 清单，形如 `{"allow":["card","skill","go"],"once":["card","skill","go"]}`
- 引擎每帧读一次；替我做完其中某一下，就把那一项从 `allow` / `once` 里删掉、写回控制文件，
  日志记一条 `[授权收回] 出牌（单次动作已执行完）`
- 所以发一次 = 动一下，后面的回合不会自己接着动；要再来一次就再发一遍
- 多项一起发是「叠加」：做完出牌收回出牌，技能/移动那两项还留着，按顺序一项项消耗
- `/appa on` 走全覆盖（FULL_ALLOW）且**不带 once**，那才是常驻；`/appa off` 清空并停进程

引擎侧实现：`Coach.once` + `_consume_acted()`，由 `tick()` 在每帧结束后统一结算
（用 `acted.what` 关键字映射回动作类别，映射表 `_WHAT_KIND`）。


## 十三、出牌评分：阈值 + PVE 血线分层（2026-11-05 主人定）

### 13.1 出牌阈值
- `PLAY_MIN = 2.5`：评分不到 2.5 一律 pass，不为了「把牌打出去」而打。

### 13.2 骰子 / 改点类牌（遥控骰子 20005、名字含「骰 / 命运 / 方向」）
全部价值是把自己精确送到升星格 / 突击格，所以只在「还能升星」且「攻击 ≥ 10」时才值得出。

- 任一条不满足 → 评分压到 0.5，必然 pass

### 13.3 PVE 血线分层（按卡牌 ID，不看名字）

| 血线 | 优先出 | 卡 |
